Getting started

There are two ways to add a show:

  • Add by URL — paste a podcast's RSS feed URL. On Mac, use ⌘N or File → Add Podcast by URL…
  • Import OPML — bring in an existing subscription list from another podcast app. On Mac, use ⌘I or File → Import OPML…; on iPhone/iPad, use the same command from the app's menu.

Podstash downloads the show's episode list and, depending on your download settings, starts fetching the most recent episode(s) right away (see Downloads & storage).

You can export your subscriptions back out to OPML at any time from Settings → Feeds → Export OPML…, or File → Export OPML… on Mac (⇧⌘E) — handy for backups or moving to another app.

The queue

Podstash is queue-first: instead of browsing each show separately, every episode you want to hear lives in one ordered queue across all your subscriptions.

  • Add All Unplayed — from the queue's "Queue Options" menu, adds every downloaded unplayed episode across all your subscriptions to the queue in one step (oldest first).
  • Reorder — drag an episode to a new position in the queue.
  • Mark played / delete — swipe a queue row (or use its context menu). On Mac and iOS, swiping puts "Mark Played" on the left and "Delete" on the right; swiping far enough performs the action automatically.

Episodes finish and advance to the next item in the queue automatically, so once it's loaded up you can just keep listening.

Playback

Podstash plays downloaded files locally rather than streaming whenever a download is available, so playback starts instantly and works offline.

  • Now Playing — full transport controls (scrub, skip, speed) live in the persistent mini player on Mac, and a dedicated Now Playing screen on iPhone.
  • Mini Player macOS — a small always-visible window with playback controls; toggle it with ⇧⌘M or Window → Mini Player. It can optionally stay on top of other windows (Settings → General).
  • AirPlay macOS — available directly from the desktop transport controls.
  • Skip intervals & speed — configurable in Settings → Playback: skip forward (default 30s), skip backward (default 15s), and a default playback speed from 0.5x–2.0x.

Downloads & storage

All of this lives in Settings → Episodes:

SettingWhat it does
Auto-download new episodesOn by default: the most recent N episodes per show are downloaded automatically on refresh. Turn it off to only download episodes you request manually.
Episodes per refreshHow many of the newest episodes to auto-download each time a feed refreshes.
Keep episodesThe retention policy: Unplayed Episodes Only, All Episodes, or Most Recent Episodes (with a configurable count).
Auto-delete played episodesOnly shown when "Keep episodes" is set to All Episodes — otherwise the retention policy above already governs what's kept. When on, played episodes are removed automatically after the configured number of days.
Clean Up Episodes NowApplies your retention policy immediately instead of waiting for the next scheduled cleanup.

The same pane shows current storage usage — total episodes and how many are downloaded, with an estimated size.

Feed refresh timing itself (how often Podstash checks for new episodes, and whether to do so only on Wi-Fi) is under Settings → Feeds.

iCloud sync

Subscriptions, queue order, playback progress, and downloaded-episode markers can sync across your Mac, iPhone, and iPad via iCloud. Toggle it under Settings → General → Sync with iCloud.

Note: sync requires an Apple Developer Program membership with CloudKit enabled on the build you're running — the version distributed on the releases page has this configured. If sync ever gets stuck, Settings → General → Reset Local Sync… clears the local database and rebuilds it fresh from iCloud.

Updates macOS

Podstash checks for new releases automatically and can install them in place, powered by Sparkle. Updates are signed and served from this site's appcast.

Toggle automatic checks, or trigger one manually, under Settings → Updates (or Podstash → Check for Updates… in the menu bar).

Search

Search is available in both the queue and a podcast's episode list — on Mac it sits at the top of the window; on iPhone, pull down to reveal it. Podcast detail search always searches across the "All" episodes tab, not just Unplayed.

Scripting & Airfoil support macOS

Podstash exposes a small AppleScript dictionary for now-playing metadata and transport control:

  • Properties: track title, artist, album, duration, logo
  • Commands: playpause, next, previous

The full definition is in Podstash.sdef in the repo, or open Script Editor's Library window with Podstash running to browse it interactively.

Setting up Airfoil

That dictionary is what powers Podstash's integration with Airfoil, Rogue Amoeba's app for streaming audio to AirPlay speakers, Bluetooth devices, and other Macs. Once set up, selecting Podstash as a source in Airfoil shows the playing episode's title, podcast name, and artwork in Airfoil Speakers, and exposes play/pause/next/previous controls remotely.

Airfoil doesn't talk to Podstash's dictionary directly — it looks for small bridging scripts in its own support folder. Podstash ships those scripts, plus an installer, inside the app bundle, so setup is a one-time step:

  1. Make sure Podstash is in /Applications.
  2. Open Terminal and run:

    /Applications/Podstash.app/Contents/Resources/install.sh

  3. Open Airfoil and select Podstash as the audio source.
  4. Play an episode in Podstash — metadata and controls should appear in Airfoil Speakers.

The installer copies two compiled scripts into ~/Library/Application Support/Airfoil/ (TrackTitles/ and RemoteControl/); re-run it any time you reinstall Podstash somewhere other than /Applications, or after a major update if metadata stops appearing.

FAQ

Why won't macOS let me open the app?

Released builds are Developer ID signed and notarized, so this shouldn't happen. If it does, make sure you downloaded the zip from the GitHub releases page rather than a fork or mirror, and that the zip fully extracted before you moved Podstash.app to Applications.

Can Podstash play video podcasts?

Not yet — it's audio-only for now.

Is there an App Store version?

Not yet. See the roadmap for what's planned.

Where do I report a bug or request a feature?

Open an issue on GitHub.
